# Payaso Mahuelin - Bubble Dreamy Edition

Landing de alta conversión en React + Vite + Tailwind.

## Estructura
- Header con logo completo (pill celeste)
- Hero
- Beneficios glassmorphism
- Galería
- CTA final con WhatsApp https://wa.me/527223352454
- Footer

## Instalación (en PC moderna, NO en Dell T3600 sin AVX2)
npm install
npm run dev

## Build
npm run build

## Nota compatibilidad
La versión de un solo HTML (payaso-mahuelin-bubble-v2.html) es la que funciona en tu Dell Precision T3600 Xeon sin AVX2. Usa esa para abrir directo en navegador.

Este proyecto React es para editar/escalar en una PC moderna.
